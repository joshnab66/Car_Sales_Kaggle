# 📊 Car Sales Data Visualization Using Excel

**Author:** Joshna Budha  
**Tools Used:** Microsoft Excel, Pivot Tables, Charts  
**Dataset:** Car Sales Dataset — Kaggle  

---

## 📌 Project Overview

This project focuses on visualizing car sales data using Microsoft Excel. I worked with a real-world Kaggle dataset containing car sales records across multiple manufacturers. The goal was to explore sales patterns, performance metrics, and customer retention rates through meaningful charts and pivot table analysis.

---

## 📁 Dataset

| File | Description |
|------|-------------|
| `Car_Sales_Kaggle.xlsx` | Raw car sales data from Kaggle containing manufacturer, unit sales, power performance, and retention data |

---

## 🎯 What I Did

### 📊 Chart 1 — Clustered Column Chart

- Filtered data to focus on **Toyota** manufacturer
- Selected Power Performance Factor columns
- Built a **Clustered Column Chart** to compare performance across Toyota car models
- Added chart title: **"Power Perf Factor of Toyota Cars"**

> 💡 **Finding:** Clear visual difference in power performance across Toyota models helps identify top-performing variants.

---

### 📈 Chart 2 — Area Chart

- Filtered data to **Toyota** manufacturer
- Built an **Area Chart** to show unit sales distribution
- Added data labels for exact values on each data point
- Formatted the series fill color to **Gold** for better readability

> 💡 **Finding:** Area chart effectively shows the volume and spread of Toyota unit sales across different models.

---

### 📉 Chart 3 — Clustered Bar Chart (from Pivot Table)

- Created a Pivot Table from the raw data
- Filtered to **Toyota** manufacturer
- Built a **Clustered Bar Chart** directly from the pivot table
- Added data labels at Inside End for clear value display

> 💡 **Finding:** Horizontal bar chart from pivot table gives a clean comparison of Toyota's sales figures by model.

---

### 📏 Chart 4 — Line Chart with Markers (from Pivot Table)

- Filtered data to **8 major Japanese auto brands:**
  - Acura, Honda, Infiniti, Lexus, Mitsubishi, Nissan, Subaru, Toyota
- Built a **Line Chart with Markers** from pivot table
- Added chart title: **"Average Retention % of Japanese Auto Manufacturers"**
- Added data labels below each marker
- Removed legend for a cleaner look

> 💡 **Finding:** Toyota and Lexus lead in customer retention among Japanese manufacturers, while Mitsubishi shows the lowest retention rate.

## 💡 Key Insights
